# 自动化任务

定义在 [`automations.json`](automations.json)（部署脚本 `--subscribe` 和技能里的「开启自动录入 / 订阅晨报」都按它创建）：

| 标题 | 频率 | 开启方式 | 做什么 |
|---|---|---|---|
| 拜访记录自动录入 | 每隔 1 小时 | 对工作伙伴说「开启自动录入」 | 处理本人过去 1 小时的新妙记，整理后请本人确认再写入；草稿超 24 小时未确认只提醒，不写入 |
| 销售晨报 | 工作日 8:30（cron `0 30 8 * * 1-5`） | 说「订阅晨报」 | 只读：快到期、已逾期、久未跟进的商机和今日日程 |

自动化属于个人账号，只处理开启者本人的数据，所以由每个销售自己开启。

## 关于「事件触发 → 妙记生成」

自动化里有「妙记生成」事件，能做到录完即处理，但创建时平台要先替用户订阅妙记事件，在验证用的租户上失败了：

```
创建事件触发器失败：事件前置订阅未成功
(event_type=minutes.minute.generated_v1, resource:/open-apis/minutes/v1/minutes/subscription, Code: 110204)
```

所以默认用每小时定时触发。要实时，可以试这个事件（接口返回 code 0 即成功），或走 DEPLOY.md 里「多维表格 → 签名中转 → Webhook」的方案。
