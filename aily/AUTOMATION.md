# 自动化任务（豆包工作伙伴「自动化」→ 新建自动化 → 手动创建）

| 字段 | 值 |
|---|---|
| 标题 | 拜访记录自动录入 |
| 指派给 | 拜访录入助手 |
| 触发方式 | 定时触发 → 每隔 N 小时 → 1 |
| 推送给 | 本人（默认） |
| 推送条件 | 仅当有新的客户拜访（需要我确认、已写入或写入失败）时推送；没有就不推送 |

描述（任务指令）：

> 用技能 visit-to-xsy 处理我在过去 1 小时内新生成的飞书妙记（包括录音豆录音）。跳过非客户沟通和已经处理过的妙记。每条客户拜访整理好后发给我确认，确认后再写入销售易；超过 48 小时未确认的，只写跟进记录并标注「AI 生成，未经确认」，不改商机阶段。没有新的客户拜访就不用发消息。

## 关于「事件触发 → 妙记生成」

自动化里也有「妙记生成」事件，能做到录完即处理。但创建时平台要先替用户订阅妙记事件，在验证用的租户上失败了：

```
创建事件触发器失败：事件前置订阅未成功
(event_type=minutes.minute.generated_v1, resource:/open-apis/minutes/v1/minutes/subscription, Code: 110204)
```

所以默认用每小时定时触发。如果你们的租户能订阅这个事件（建一次试试，接口返回 code 0 即成功），可以改成事件触发，把指令里的「过去 1 小时内新生成的妙记」换成「刚刚生成的这条妙记」。
