# 介绍卡片配图的生成提示词

用 GPT 生图（本仓库用 `codex exec -m gpt-6-sol`），并把**录音豆产品图作为参考图**传进去，保证画出来的设备和真机一致：

```bash
codex exec --skip-git-repo-check -m gpt-6-sol -s workspace-write -C <输出目录> -i ref-desk.png -i ref-float.png -i ref-wear.png < prompt.txt
# 原尺寸图在 ~/.codex/generated_images/<会话>/exec-*.png；飞书卡片图片宽度 ≤1500px：sips --resampleWidth 1500 in.png --out out.png
```

参考图需自备：从飞书官网「飞书 × 安克 AI 录音豆」介绍页截取产品特写（`ref-desk.png` 桌面特写、`ref-float.png` 悬浮特写、`ref-wear.png` 三种佩戴方式）。官方产品图版权属于飞书 / 安克，不随本仓库分发。

经验：只说「录音设备」GPT 会画成胶囊形；要写清「有厚度的圆饼/冰球形、厚度约为直径三分之一、侧面按键和接口、扁平白色编织带挂环、正面两条网格孔 + 橙色指示灯」，并附参考图。
