# 介绍卡片配图的生成提示词

用 GPT 生图（本仓库用的是 `codex exec -m gpt-6-sol`）：

```bash
codex exec --skip-git-repo-check -m gpt-6-sol -s workspace-write -C <输出目录> < prompt.txt
# 原尺寸图在 ~/.codex/generated_images/<会话>/exec-*.png；飞书卡片图片宽度 ≤1500px，用 sips --resampleWidth 1500 缩放
```
