# 用户故事：销售在飞书里用工作伙伴操作销售易

角色：一线销售（下文「我」）。入口：飞书里的工作伙伴「拜访录入助手」（豆包工作伙伴）。

**总原则：查询直接执行；任何写入销售易的操作都必须销售本人明确确认。**
数据：通过官方「销售易 CRM」连接器，以销售本人的销售易身份读写，只看得到、改得了本人有权限的数据。

优先级：P0 第一版必须有；P1 第二版；P2 以后再说。
「已验证」= 用 `scripts/verify-sales-assistant.mjs` 在销售易沙箱里实际跑通了对应查询。

## 不做（这一版）

- 新建客户 / 联系人 / 商机，赢单、输单、删除、转移负责人：影响大，留在销售易里操作。
- 看别人的数据：只处理本人负责的记录，主管视角以后单独做。

## 口径（写进技能，避免每次理解不一样）

| 说法 | 口径 |
|---|---|
| 我的商机 | ownerId = 我，status = 1（进行中） |
| 快到期 | 结单日期在今天 ~ 今天 + 7 天（「两周」= 14 天，「本月」= 到月底） |
| 逾期 | 结单日期 < 今天，且仍进行中 |
| 久未跟进 | 最近活动记录时间 < 今天 − 14 天，或从未跟进 |
